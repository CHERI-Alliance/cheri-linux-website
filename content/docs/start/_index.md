Whether you want to experiment with CHERI concepts in a virtual environment or work directly on CHERI-enabled hardware, there are several paths to get started. This page collects guides for the most common setups: running Debian under QEMU for a lightweight, general-purpose Linux experience; running Morello Linux under QEMU, which targets Arm's Morello prototype architecture; and configuring a physical Morello development board for those who want to work with real CHERI hardware. 

Pick the guide that matches your goals to get up and running:

* [Debian on QEMU](/docs/start/debian-on-qemu/)
* [Morello Linux on QEMU](/docs/start/morello-on-qemu/)
* [Morello development board](/docs/start/morello-board/)
